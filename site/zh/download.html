安装

Windows

运行安装程序即可。它按当前用户安装，不需要管理员权限；缺少 Microsoft WebView2 时会自动装上。

卸载：设置 → 应用 → 已安装的应用 → SwiftDL。

macOS

打开 .dmg，把 SwiftDL 拖进“应用程序”。需要 macOS 10.13 或更高版本，同一个安装包支持 Apple 芯片和 Intel。

卸载：把 SwiftDL 从“应用程序”移到废纸篓。

Linux

chmod +x SwiftDL_*.AppImage
./SwiftDL_*.AppImage

sudo apt install ./SwiftDL_*.deb
sudo dnf install ./SwiftDL-*.rpm

关于安全警告

SwiftDL 的安装包还没有代码签名，因为签名证书每年都要付费。所以第一次打开 SwiftDL 时，系统可能会提示无法识别发布者。

Windows

如果 SmartScreen 提示“Windows 已保护你的电脑”，点更多信息，再点仍要运行。

macOS

如果 macOS 提示无法验证开发者，在“应用程序”里右键点击 SwiftDL 选择打开，再点一次打开。

请只从本站或 GitHub Releases 下载 SwiftDL。每个文件都由 GitHub Actions 从公开源码构建。

浏览器扩展

应用已自带：打开 SwiftDL，点击添加扩展查看简短指引。支持 Chrome、Edge、Brave 和 Vivaldi。Firefox 请从 Firefox Add-ons 获取。

从源码构建

你需要 Rust，以及对应系统的 Tauri 前置依赖。

git clone https://github.com/harshsinghsv/swiftdl
cd swiftdl/app/src-tauri
cargo install tauri-cli --version "^2"
cargo tauri build
