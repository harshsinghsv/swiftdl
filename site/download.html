Installing

Windows

Run the installer. It installs for your user only, so it doesn't need admin rights, and adds Microsoft WebView2 if it's missing.

To uninstall: Settings → Apps → Installed apps → SwiftDL.

macOS

Open the .dmg and drag SwiftDL into Applications. macOS 10.13 or later, one build for Apple silicon and Intel.

To uninstall: move SwiftDL from Applications to the Bin.

Linux

chmod +x SwiftDL_*.AppImage
./SwiftDL_*.AppImage

sudo apt install ./SwiftDL_*.deb
sudo dnf install ./SwiftDL-*.rpm

About the security warning

SwiftDL's installers aren't code-signed yet, because signing certificates cost money every year. So the first time you open SwiftDL, your system may warn you that it doesn't recognise the publisher.

Windows

If SmartScreen says "Windows protected your PC", choose More info, then Run anyway.

macOS

If macOS says it can't verify the developer, right-click SwiftDL in Applications and choose Open, then Open again.

Only download SwiftDL from this site or GitHub Releases. Every file is built from the public source code by GitHub Actions.

Browser extension

Included with the app: open SwiftDL and click Add the extension for a short guide. Works in Chrome, Edge, Brave and Vivaldi.

Build from source

You need Rust and the Tauri prerequisites for your system.

git clone https://github.com/harshsinghsv/swiftdl
cd swiftdl/app/src-tauri
cargo install tauri-cli --version "^2"
cargo tauri build
