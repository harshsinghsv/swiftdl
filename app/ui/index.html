Add the browser extension

The extension came with SwiftDL. Add it in four steps; this window notices as soon as it connects.

  1. 1
    Open the extensions pageType chrome://extensions in the address bar
  2. 2
    Turn on Developer modeThe switch is in the top-right corner of that page
  3. 3
    Click Load unpackedA folder picker opens
  4. 4
    Choose SwiftDL's extension folderThe path is already copied, so paste it into the picker…

Waiting for the extension to connect…

Use this folder rather than a downloaded copy: it stays in place while SwiftDL is installed and is refreshed when SwiftDL updates.

Seeing two download windows? Turn off “Ask where to save each file before downloading” in your browser's download settings. The browser asks before SwiftDL can take over.
